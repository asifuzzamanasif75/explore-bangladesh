# Explore Bangladesh

Student ID: 2211281
Student Name: Md. Asifuzzaman

## Project
A five-page basic HTML and CSS website about Bangladesh.

## Pages
1. Home
2. Dhaka
3. Cox's Bazar
4. Sylhet
5. Heritage

## Requirements covered
- 5 separate HTML pages
- Interlinked navigation bar
- At least 2 paragraphs on every page
- At least 2 images on every page
- External anchor links
- Shared CSS file
- Margin, padding, colors, fonts, shadows and responsive styling
- HTML/CSS comments
- Two Google Fonts: Montserrat and Playfair Display
- Flexbox used on multiple pages
- CSS Grid used on Cox's Bazar and Heritage pages
- Ready for GitHub and Netlify static hosting

## Netlify
This is a static website. Upload the project folder to a GitHub repository and import that repository into Netlify.
